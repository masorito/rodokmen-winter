# Dům čp. 332/333, Podmokly (Bodenbach): časová osa 1806–dnes

*Dnes Třída Čs. mládeže 47, Děčín IV, kavárna Kytky pod komínem.*
*Hlavní prameny: pozemková kniha k. ú. Podmokly, vložky 643 (dříve Weiher 39) a 1411 (kopie KÚ Děčín, 16. 11. 2026); stavební spis domu; matriky SOA Litoměřice; adresáře; dobové fotografie.*
*Značky: [doloženo] = přímo z pramene; [pravděpodobné] / [domněnka] = náš výklad.*

### Majitelé domu přehledně
Zeischke (do 1887) → Langecker (1887) → Ernst / Wurzner (1888) → dražba 1896 → J. H. Sonntag (1897) → Marie Sonntag (1902) → Otto Sonntag (1908) → **Rudolf a Franziska Winterovi (1911)** → **Franziska Winter sama (1927)** → Československý stát (1949/1952) → … → dnešní majitelé.

### Otevřené otázky
- Kdy a pro koho byl postaven vysoký komín? Nejpravděpodobněji pro pletárnu (1892), ale nedoloženo.
- Kdo byli manželé Russovi a proč Fanni půjčili? Příbuzní, nebo známí?
- Další vlastníci po roce 1952 (pozemková kniha byla uzavřena zákonem č. 22/1964 Sb., dál vede katastr nemovitostí).
